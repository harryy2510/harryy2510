I build production systems from messy product ideas. Over the last decade I have shipped SaaS platforms, mobile apps, realtime products, payment systems, analytics pipelines, and internal tooling across companies like **GrowthDay**, **Appointy**, **Google**, and **Telefonica**.

At **GrowthDay**, I built most of the Next.js/React/TypeScript platform from scratch and helped scale it from **10K to 400K+ users** while leading **15+ engineers**. Earlier at **Appointy**, I worked on a **1M+ user scheduling SaaS**, including React scheduling products for Google and Telefonica.

These days I spend a lot of time turning AI-assisted development into a real engineering workflow: repo rules, reusable skills, specialist agents, type checks, tests, and guardrails instead of one giant prompt.
